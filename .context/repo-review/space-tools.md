**Relationship review, verified by reading the code: space and tools**

Area: `space/work_state.py`, `space/session`, `space/repo`, `space/kanban` (Python, and the hand-written TypeScript clients of the board app), and every package under `tools/` (echo, granola, prompt_log, prompt_notify, file_manager, sub_agent). Every entry below was checked against the code as it stands on 2026-11-07; line numbers are the current ones, which have moved from those in `.context/repo-runtime.md` in several files. Spec files, story tests, and spec-support classes (`ThrowawayProject`, `session_board_examples.py`, `session_board_tiers.py`, `story_test.py`) are outside "production" and are only noted where they matter.

Verdicts: **R** — right as a runtime dependency: two independent objects, one asks the other to act (an external system, a collaborator it holds or is handed, a registry, a value or result record it returns, a factory that loads by the identity it is handed). **W** — wrong shape: built per call from strings or paths, a file another object holds read again, an owner's data passed into a helper, or a reach through to construct what should be held.

Two findings run through many entries below, so they are stated once here:

- **One `.sessions/session.json`, four owners.** `WorkState` is built from a folder path by `Repo` (repo.py:272, :281), `Sessions` (sessions.py:43, :68), `Session` (session.py:240), and `LatestRelease` (latest_release.py:37). Each reads the same file again. The main clone's `Repo` should hold the one `WorkState` (composition 1); `Sessions` and `LatestRelease` are handed that repository and ask it.
- **The main clone is rebuilt from paths, not held.** `Repo(Repo(project).checkout_folder).primary_root()` and its variants appear in `Board.load` (board.py:97), `Sessions.__init__` (sessions.py:41), `Repo._checkout` / `_main_clone` / `_checkout_tools_act_in` (repo.py:262, :268, :282), and `Worktree.close` (worktree.py:100). `Worktrees` already knows the main checkout; `Repo` should answer `main_clone` from it, and every one of those callers reads it.
