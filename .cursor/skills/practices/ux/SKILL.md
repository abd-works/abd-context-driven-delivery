## Overview

UX maps how users see and act on the product: screens, regions, controls, and the transitions between them. Deepen from information architecture to a runnable greybox, then to the shipping frontend. Each fidelity adds artifacts; it does not invent detail from a later one.

ia — Decide what screens exist and how users move between them.

Use MCP tool: `ux-ia()`

mockup — Lock screens as runnable greybox — typed controls and key interactions.

Use MCP tool: `ux-mockup()`

front_end_code — Ship the product UI — production frontend talking to a real backend.

Use MCP tool: `ux-front-end-code()`
