# Agent Orchestration

Guide work with agent definition files like the ones we already have: role agents such as a Product Owner, and stage agents such as the Discovery agent. Each one shapes the activity in its part of the work. A Delivery agent could then orchestrate them, handing work from one agent to the next.

Prerequisites:
- A working correction loop, so that agents learn from the user's corrections. It is broken at the moment.
- Good evals, so we can tell whether the agents and the orchestration actually do the work well.
