# Chat bar shows the robots' queue as clearly as a drawn card view

When sub-agent mode is on, the chat bar's prompt queue shows one block per robot: its name, a status badge (working, waiting, decision required), its current card first and in full, and its waiting cards dimmed beneath it. Today it reads as one flat list, which is harder to scan than the drawn card view Claude made in the release-1-2-fixes chat on Nov 18. The pane is a fixed-width terminal, so the blocks stack instead of sitting in a grid.
