## Failure the chat bar showed

Reproduced in this chat: `board.overview` and `sessions.current` both answered "still running after 10 seconds"; `cdd.ping` answered `pong` (it runs on the event loop).

## Cause

The dev-lane cdd server (pid 34724, port 47801, pinned to release-1-2-fixes `0d29115`) had one AnyIO worker thread holding the GIL in a Clean Engineering model render to drawio, started 21:09 UTC by the release-1-2-fixes chat (`render C:\dev\abd-cdd-release-1-2-fixes clean_engineering model python`, its session.log). It ran 6+ minutes. Every other worker-thread call (board reads, chat check-ins) starved. Two py-spy dumps a minute apart showed the same thread `active+gil`:
