## Key Learnings

No corrections document with starred rules exists for this session (`.sessions/_backlog/corrections.md` is a backlog note, not a corrections document). These are the person's corrections and decisions from this session:

- **A module is not a package.** A module must have a module-context file. Module measures are nested: imports from any file of the module or its packages count, including into child modules.
- **Rules are generic.** They fit diverse projects and never name this codebase's own names. A rule can have scope "all", meaning the whole repository.
- **Edge and error cases are scenarios**, never a separate table.
- **Only an agent reading both can decide what to do with a render leftover.** Whether a part was written by hand or generated has no bearing.
- **"Model" means the model fidelity in any format** (code, markdown or diagram), not markdown.
- **The fidelity with the most detail is the source of truth.** Differences between fidelities are reported by a repository's end-to-end test, not by a load. A graph is loaded in the format selected and does not cross formats.
- **Lizard is the one measuring tool.** The parameters limit is 3. The limit on lines of a method was contested and kept at 50. No stopgaps for backlog ideas.
- **Unused code is deleted once every way it can be used is checked.** A kept test seam is recorded as an accepted violation with its reason, not hidden in config.
- **An answer of the person's that arrives cut off is dropped**, never asked again. Never wait on a decision: go on with the next item.
- **The person is on Remote Control.** Every closing message stands on its own, in plain English, with no jargon and every metric spelled out.
