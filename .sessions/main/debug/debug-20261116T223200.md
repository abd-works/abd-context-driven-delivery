## Likely cause

The story_map fidelity now writes `.context/story-map.whiteboard`, a Stories board. Clean Engineering's CodeRead picks a format by file extension (`formats.for_file`), so it sends that board to the whiteboard class model, which raises UnreadableBoard. That one unreadable file stops the whole graph build. Other .whiteboard files in the repository: `.sessions/_complete/claude-whiteboard/boards/*.whiteboard` and `cdd_guidance/practices/stories/model/_examples/actual/*/to-whiteboard/story-map.whiteboard`.
