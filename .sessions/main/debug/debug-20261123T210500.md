# Board Delete does nothing in Claude's Browser pane: window.confirm answers No by itself

## What the person did

Pressed Delete on the open card of the ticket feature-taimur on the CDD Session Board (stable lane, http://127.0.0.1:8778, project C:\dev\abd-context-driven-delivery), in Claude Desktop's Browser pane. Nothing happened: no dialog, no toast, the card stayed.

## Cause

`space/kanban/app/src/kanban/ticket/card-upkeep-view.tsx`, DeleteView:

```ts
const deleted = () => window.confirm(`Delete ${ticket.title} and its session folder? This cannot be undone.`) && ticket.delete()
```

In the Browser pane the browser's own confirm dialog never shows and answers false at once (probed on the open board: `window.confirm('probe')` returned `false` with no dialog). So the delete is cancelled before any call leaves the page: neither the stable server log (~/.cdd/server.log) nor the dev lane log holds a ticket.delete call for feature-taimur.

The browser story test hides this: maintain-tickets.story.ui.spec.ts accepts the native dialog with `page.once('dialog', dialog => void dialog.accept())`, which a real Browser pane never does.

## Fix

Ask in the board's own dialog, as the Close dialog does (`activation-view.tsx`): a Delete dialog with Cancel and Delete, Escape cancelling. The story test presses the dialog's Delete button instead of accepting a native dialog.
