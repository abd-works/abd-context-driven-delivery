Deleting a ticket fails on Windows when setting its folder aside makes a file's path longer than 260 characters.

## What the person saw

The CDD chat bar above the prompt shows this failure. Failure: cdd ticket.delete failed: FileNotFoundError: [WinError 3] The system cannot find the path specified: `C:\dev\abd-context-driven-delivery\.sessions\_removing-scheduled\e2e-test-results\move-work-forward-on-session-board\maintain-tickets\run-2026-11-17-19-36-01\screens\delete-ticket-delete-a-ticket-and-its-session-folder-1-given-the-ticket-pet-visits-is-on-the-board.png`. Context: Calling /ticket/scheduled/delete from the Kanban board.

## Steps that led to it

1. On 2026-11-23 a delete of `scheduled` renamed `.sessions\scheduled` to `.sessions\_removing-scheduled` and stopped part way, leaving 605 files there.
2. On 2026-11-26 a second delete failed with `FileExistsError: [WinError 183]`, because the rename's target was already there.
3. Commit `ea9a407b2` made a delete remove the leftover folder first. That removal now fails with the error above.

## Measured

| Folder | Files | Longest path |
|---|---|---|
| `.sessions\scheduled` | 52 | 249 characters |
| `.sessions\_removing-scheduled` | 605 | 290 characters |
| `.sessions\_removing-local` | 71 | 282 characters |

Windows refuses a path over 260 characters unless it is given in its extended-length form. Setting a folder aside adds the ten characters of `_removing-` to every path in it, which takes the end-to-end screenshots past the limit.

## Related finding

`scheduled` is not a ticket a person made. `harness/e2e_review/e2e_review.py` line 339 names it as the folder the scheduled end-to-end run writes its results to, `.sessions/scheduled/e2e-test-results`. The board lists every folder under `.sessions` as a ticket, so it shows as one, and it comes back after a delete on the next scheduled run.

## Suggested fix

In `space/session/session_folder.py`, `_remove_files_of` removes the folder by its extended-length path on Windows, so a path over 260 characters is still removed. Separately, decide whether the board should list the scheduled run's results folder as a ticket.
