## Key Learnings
The corrections document (`.sessions/_backlog/corrections.md`) holds no rules yet, so these come from this session:
- No fallback to the system browser, ever: pages open only in the Claude app's browser pane; fix the app instead. (user correction this session)
- After `/reload-plugins` leaves plugin:cdd:cdd "failed", re-dial it with the desktop app's `reconnect_session_connector`; a reload alone keeps the failed connection.
- The installer publishes the board mod and adapters from the pinned runtime, and a plain install re-pins only when the runtime is older, so mod changes reach chats only after the pin moves.
- Other agents commit and merge in this same checkout (a merge of integrate-practice-content-editor-apps ran mid-session); check `git status` before committing and commit the whole worktree.
