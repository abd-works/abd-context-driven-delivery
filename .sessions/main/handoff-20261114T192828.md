## Key Learnings
No session block exists in the corrections document (`.sessions/_backlog/corrections.md` holds only a note), so these are the user's corrections from this session:
- never-stash: never run `git stash`; other agents commit in this checkout.
- unit-tier-only-unasked: never run heavy or e2e specs unless the user asks.
- test-before-shipping-a-visible-fix: before committing and pushing a fix the user must see, run quick checks only (a spot check, the specs for the files touched, `claude plugin validate`, a build); never long suites, and no heavy or e2e unasked.
- subtask-means-subagent: a "subtask" is a subagent, not a new session.
- validate-chat-bar-before-publishing: run `claude plugin validate .` in `harness/chat-ui/pane` before publishing any chat bar edit; a refused module hides the whole chat bar silently.
- short-status: the user wants speed and short status, not long explanations.
