## 1. Summary

The release-1-2-fixes chat began on 2026-11-18 as the standing fix chat for CDD v1.2.0: other chats sent bug reports, and this chat fixed each one on its own branch with automated tests. The first day fixed about twenty reports from the Nov 18 demo. From 2026-11-19 the work turned to finding defects before people did. Robots ran exploratory testing in three rounds: round 1 explored the tools and workflows at their edges, round 2 reproduced each defect from its report and took the areas round 1 missed, and round 3 took every fidelity of every practice through every format, first one practice at a time and then all five practices in one project. Together they wrote 156 reports: 128 defects and 28 questions for the person, three of which the person's answers turned into defects. Fixing them found 14 more. Of the 131 defects from the reports, all but a few are fixed; the ones still open are listed in section 7.

The defects fall into ten themes (section 3). Rounds 1 and 2 found faults at the edges of the tools: two callers on one file, names and paths taken as given, unreadable files read as empty and written over, and records that outlive what they describe. Round 3 found faults in the practices themselves: a format that holds less than markdown saved over it, a graph that joins things by a shared name, and formats or files offered with nothing that reads them. The fixes then added their own theme, regressions, because each fix ran only its own specs until the unit tier ran after the wave.

Almost none of this was caught by the automated tiers. Before the fixes began, the unit, heavy and e2e tiers were green on every one of the defects the robots then found; the unit tier should have caught about seven in ten of them (section 4). The tests were present, but they covered the path the author had in mind: one caller, a prepared repository, the one spelling the author used, one direction of each format adapter. The tests that take every format of every fidelity there and back were written only on 2026-11-22, after the defects ([format_trip_spec.py](C:\dev\abd-cdd-release-1-2-fixes\cdd_guidance\practices\format_trip_spec.py)).

From 2026-11-21 the session ran a Clean Engineering review of the whole codebase: a validate of the code fidelity (388 graph findings), seven judges reading every production file (about 1,100 findings and 86 proposals), the proposals merged into 25 plus 13 smaller changes, and four rounds of refactoring that built all of them but one smaller change, X5 (the board's cards through a registry), which was deferred. The person then had the cross-file Clean Engineering checks and the code measures built as graph rules, so the next validate checks what the judges found by hand. The refactor introduced its own errors, from merge slips to an import loop; section 5 names, for each, the metric or graph rule we have now that would have caught it, and says plainly where none would. The validate run after the refactor reported 2,733 violations against 388 before. The code did not get seven times worse: 1,831 of those are three measured-limit rules saying the measuring tool, lizard, is not installed on the dev lane, and most of the rest come from rules that did not exist at the first run (section 6).

On 2026-11-23 and 2026-11-24 six robots worked what the review left open (wave 7): lizard installed, a check that every name the code calls or imports still exists, the last two open defects and the parts left of fourteen others, every question the person answered built, a second judge round, one node in the graph for a class a model document and its code both describe, and the metrics gate replaced by validate rules. A validate of the whole code at the end ([clean-engineering-code-20261124T074203.md](C:\dev\abd-cdd-release-1-2-fixes\.sessions\release-1-2-fixes\validation-reports\clean-engineering-code-20261124T074203.md)) finds 1,058 violations in 27 rules, with every measured limit measured: the eleven rules the first run also checked find 339 where they found 256, and the seventeen that found nothing at the first run, most of them added since, find 719 (section 6). A second judge round on the 613 production files changed since 2026-11-21 found 1,337 findings, 586 of them the first round's still open; none of the second round's has been fixed beyond four defects.

Later on 2026-11-24 (wave 8) the person's own use of the chats found four more faults, each fixed: a whiteboard render ended without creating its board in Claude; a dev-lane install wrote its mods into the stable lane's marketplace, so main's chats got a Flush button their server could not serve (issue 105); Claude Code kept loading a cached copy of each cdd plugin, so a repin never reached a chat; and the prompt queue filed questions and comments as work and kept its robots after sub-agent mode was switched off.

The tiers at the end, on `a34fa3501` (2026-11-24): the unit tier passed 476 of 476 files; the heavy tier passed 77 of 77 files, at `f25dcfc3e` and again on the final code at `203eac4a6`; the e2e tier passed 9 of 12 files at first, then 12 of 12 (Playwright 241 of 241) once `96d944ccf` brought three specs up to two answers already built: the Files app's graph-view specs looked for the `kanban` label a folder had before the explorer tree labelled it by its path at the practice's root, `space/kanban` (r3-lens-09, `0ba9d8958`), and the board's render test unchose the last chosen format, which widget-13's answer refuses.
