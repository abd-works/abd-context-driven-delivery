## What is done

- **Chat link proven in the desktop chat.** A page button started a real turn, a skill ran from the mod's timer, and Fill reached the box. Results: `.sessions/session-board/chat-pilot/results.md`.
- **Language adapter, a new installer channel.** `@language_adapter(language="typescript")` on a toolset class deploys `<install path>/language-adapters/typescript/<source folders>/<object>.ts`: `{Object}Data`, `{Object}` with camelCase getters, and `{Object}Tools` calling that object's own tools, plus `cdd-connection.ts` and a `package.json` declaring ES modules. Code: `harness/installation/language_adapter.py`. Marked: `Board`, `Ticket`, `BacklogItem`, `Session`, `Repo`. Most other toolsets return prompt text, so they stay unmarked.
- **Python contracts.** `harness/kanban/data.py` holds `TypedDict`s, so `TicketData` is generated rather than hand-kept.
- **Patterns.** New `cdd_guidance/patterns/cdd_access/` with graph rules. LERN gained **Testing with BDD**, a BDD overlay with four graph rules, shared-behavior templates, and **CDD-backed aggregates**. The Claude mod pattern takes types from the adapter. Enabled in `.context/config.json`: `cdd_access` and `lern_domain_driven`.
- **Graph.** A folder holding `<slug>-routes.ts` or `<slug>-node.ts` under `src/` is now an aggregate even with no domain class, and a test folder never is. Without this, LERN rules reached only `board`.
- **The app.** `packages/session-board/` boots it. `src/kanban/{board,ticket,backlog-item,chat}/` hold each object's node, routes, client, and views. `{Object}Client extends {Object}` from the adapter. Routes ask nodes, nodes parse requests with Zod, one middleware answers failures.
- **Tests.** Four sub-epics in `tests/kanban/` (move-ticket, backlog-items, wip-limits, files-and-reports) run one `.spec.shared.ts` on the server tier with real cdd, the Playwright tier, and the e2e tier. `kanban_tools_spec.py` checks the shapes against `data.py`, and that each shared sentence exists in Python.
- **Retired.** `retired/harness/kanban/`: the pane, `desktop_pane.*`, the old surface spec, `canvas-differences.md`.
- **`repo.py`:** checkout, merge, and worktree get the 180-second git limit, because a timed-out checkout left a half-switched clone.

## Known findings left on purpose

Graph runs over the app report these. None is a design problem:

- `bdd:no-implementation` and `bdd:framework-syntax`: behavior-fidelity rules applied to finished tests by a run that names no fidelity.
- `one-home-for-web-paths` on slash commands such as `/actions-validate`, which look like paths.
- `every-class-carries-ddd-stereotype`, `no-orphaned-objects`, `use-explicit-dependencies` on page plumbing such as `BoardPage`.
- `limit-operation-parameters` on `answerFailure`, which Express needs to take four parameters, and `createApp`.
- `keep-operations-single-responsibility` guesses, and `TicketClient` at 14 operations.
