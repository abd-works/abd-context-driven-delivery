## Key Learnings
No corrections document exists in this project (searched `.sessions/**/corrections.md`, `.sessions/main/`, `.context/corrections.md`). The main corrections this session:
- Diagnose the cause, not the symptom — refusing missing paths hid why the chat passed repo-relative paths.
- Suspect your own recent change first — delivery broke when the mod moved from `$.command.run` to `$.prompt.submit`.
- Commands must always show in the chat; never swallow a failure in the mod.
- Follow commands as sent (memory: follow-commands-as-sent).
- Deploy the front end before the long test runs.
