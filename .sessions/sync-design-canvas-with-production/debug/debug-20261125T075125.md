## Where the size comes from

I read the whole saved answer (74,106 characters) as JSON and measured each part:

| Part | Characters |
|---|---:|
| `active.text` (the ticket's idea file, a 25k-character plan) | 24,973 |
| `active.progress` (17 fidelities) | 27,205 |
| `active.stage_work` | 8,742 |
| `active.session` | 2,185 |
| `fidelities` | 3,048 |
| `columns` | 1,990 |
| `practices` | 767 |

`BoardOverview.active` sends `Ticket.in_overview()`, an `OverviewTicket`. That class trims the children to their names but still sends `text` whole. The chat bar (`harness/chat-ui/pane/hooks/chat-bar/*`) never reads `ticket.text`.
