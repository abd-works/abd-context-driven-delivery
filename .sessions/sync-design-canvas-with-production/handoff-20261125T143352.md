## Key Learnings
- Build against the current site, not a package restored from git history: a stale stylesheet makes the canvas lie about production.
- Media queries read the browser window; a canvas screen is a frame inside it. Rewrite them to container queries at build time.
- pml-web canvases are yours. The CDD chat treated them as read only and worked on a scratch copy.
