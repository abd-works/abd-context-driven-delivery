Install
  1. Get the repository: https://github.com/abd-works/abd-context-driven-delivery.
  2. Add it to your project (clone into the workspace or add it as a sibling checkout the agent can see).
  3. Drop installation/harness.py into the chat and ask the agent to run generate (action generate). That deploys each context tool as an IDE skill shim.
