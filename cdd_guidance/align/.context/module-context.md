# cdd_guidance/align
Format alignment: whether the formats a session chose for each fidelity hold the same thing, and bringing them in step. It runs the Render action, so it sits beside the actions in cdd_guidance, and the session it works on imports neither it nor Render. It is not an action of the action catalogue: every folder of `cdd_guidance/actions` is one, and the chat bar offers each on every fidelity, while alignment works on a whole session. It is published as its own toolset, *FormatAlignment*, which the Files app's Diagnose and Align buttons call.

*SessionAlignment* (`format_alignment.py`) says whether the formats a session chose for each fidelity hold the same thing, and brings them in step. `format-alignment.diagnose_alignment` goes through the fidelities the session's guidance selection covers and answers an *AlignmentDiagnosis*, each *AlignmentGap* in plain words with its kind, file, and the file it is aligned from: a chosen format whose file is not there (`missing_file`); a file that lacks nodes or edges another format of the same document holds (`format_lacks`), or two that each hold something alone (`formats_conflict`), compared as *GraphReading*s, what the knowledge graph reads from each file once the Render action has put it in the fidelity's leading format (a comparison graph and folder apart from the session's, private to `format_alignment.py`); and, from *CalloutAlignment* (`callout_alignment.py`), a link whose target is not there, a callout to a heading that no edge of the session's graph matches, and an edge between a markdown file and another document or code file that no callout shows. `format-alignment.align_formats` renders each gap a render closes through the Render action, so a drawing keeps its layout and a document its own words, and answers an *AlignmentResult*: each *AlignedFile*, each *AlignmentFailure* (kind, file, message), and the diagnosis afterwards. A missing file is rendered from the leading format, the first chosen document format; a file that lacks is rendered from the one that holds more, except the leading format, which no render writes into: what another format holds and the source lacks is handed to the agent in the gap's message, to decide by reading as a render's `migrate` is; files that conflict are left as they are, and each item one of them holds alone goes to the agent's decide pass with the leading format as the source (the lead's answer of 2026-11-22); while two files of a document conflict none of its files is rendered. A chosen code format with no file is rendered too, from the first chosen format whose file is there, into the files the fidelity declares; a code file already there takes the new shape and keeps every line it held, each *AlignedFile* naming as `migrate` the members that file keeps though its model no longer holds them, and code the declared paths cannot place, or a render that would lose a line, is answered as `render_failed`. A diagnosis searches the session's folders again first (`FileManager.search_again`), so it holds a file written a moment ago.

- **Purpose:** Find every gap between the formats of a session's fidelities and close the ones a render can close, handing each item one file holds and another lacks, where no render may close it, to the agent's decide pass.
- **Seam (terms):** FormatAlignment (the toolset: `format-alignment.diagnose_alignment`, `format-alignment.align_formats`, `FormatAlignment.load(session, call)`; `@language_adapter(language="typescript")`, whose client is `@cdd/align/format-alignment`), SessionAlignment (`diagnose`, `align`), AlignmentDiagnosis, AlignmentGap, AlignmentResult, AlignedFile, AlignmentFailure, GraphDifference, GraphReading, CalloutAlignment.
- **Dependencies (one-way):** `cdd_guidance/actions/render` (*Render*, *RenderResult*), space/session (*DocumentGraph*), space/session/files (*FileTooLongToShowError*, *NamedPathNotFoundError*), `harness/agent_tools`, `harness/installation`, `harness/mcp`, `harness/graph` (*SavedGraph*), `harness/markdown` (*Format*), `harness/diagnostics` (`raised_by_a_bug`). Nothing in space imports it.

## Constraint

Align saves through the Render action alone, so a drawing keeps its layout and a document its own words; never write a format's file here.
