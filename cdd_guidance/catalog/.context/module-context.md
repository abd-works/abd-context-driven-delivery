# cdd_guidance/catalog
*Catalog* is the generated CDD catalog: self-contained HTML pages for every practice, fidelity, action and tool, with the shared scripts and styles in `commons/` and worked examples in `examples/`. `harness/catalog_generator` writes it from the live guidance; `catalog.generate_catalog` renders it again and `catalog.apply_brand` lays a brand over it.

- **Purpose:** Show the whole of CDD in pages a person can browse, generated from the same guidance agents follow.
- **Seam (terms):** the pages (`index.html`, `workflow.html`, `fidelities.html`, …) and `commons/`
- **Dependencies (one-way):** generated by `harness/catalog_generator`; nothing imports it.

## Constraint

Generated, never edited: change a template under `harness/catalog_generator/templates` or the guidance it reads, then generate again. A file here with no template behind it (such as `commons/catalog-foundry-tour.js`) is lost on the next generation.
