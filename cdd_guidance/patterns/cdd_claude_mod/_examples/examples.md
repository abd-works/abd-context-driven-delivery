# Examples

The worked reference is `harness/kanban/`: the Python domain and `Kanban` toolset, with `pane/` as the `cdd-board` mod. The rules live in `cdd_claude_mod.md`; that folder is the concrete shape they produce.

The pane predates this pattern, so its client and view functions still sit in `register.tsx`. Treat `pane/hooks/<domain>/` in `templates/` as the target shape for new work.
