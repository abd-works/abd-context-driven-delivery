# Story UI editor (`cdd_guidance/practices/stories/app`)

- **Purpose:** the page a person edits a Stories file in, beside the chat: the story map as epics, sub-epics, stories and scenarios, edited in place. Moved here from its own repository (`C:/dev/story-ui`, 2026-11-12) to sit beside the Stories practice whose model it edits, as the Graph app sits in `harness/graph/app`.
- **Seam (terms):** `StoryMapClient` (extends the generated `StoryModelClientGenerated`), `StoryMapApi` (the page's `CddApi`), `StoryMapWorkspaceView`; for a server, `storyMapRoutes` and `storyMapBuild` (`story-map-routes.ts`) and `STORY_MAP_PAGE` (`/story-map`, `story-map-page.ts`).
- **Domain:** none of its own. Every rule and every edit is the Python story model's (`cdd_guidance/practices/stories/model/story_model.py`: `StoryModel`, `Epic`, `Story`, `Scenario`, `Step`, saved through `OpenedStoryMap`), reached through the generated adapter (`@cdd/practices/stories/model/*`), with the formats chosen for the fidelity through `FidelitySessionOutput` (`@cdd/space/session/fidelity-session-output`). No JSON or database story map: the file it was opened from is the store.
- **Served:** by the board's server on its port (8778), at `/story-map`, with `storyMapRoutes` under `/api`. `npm install` then `npm run build` writes `dist/`, which that server serves. `?file=<path from the project>` opens a Stories file; with none the page follows the story map of the session open in the project, read every two seconds.
- **Constraints:** source only: `node_modules/` and `dist/` are ignored, so neither the runtime pin (a git checkout) nor an install carries them; the toolset walk skips `node_modules`. A failed call says what failed and how to fix it, and the page keeps the map as Python last sent it (`fail-loud-on-mcp`). Increments and examples are not sent by the Python story model yet, so the views draw none and their editing controls stay hidden.
- **Tests:** `npm test` (type check and `story-map/story-map-client.spec.tsx`, jsdom); the story map tools are specified against a real cdd server in `cdd_guidance/practices/stories/model/story_map_edits_spec.py`.
