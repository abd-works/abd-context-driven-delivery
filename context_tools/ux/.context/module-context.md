# Ux (IA / mockup / front_end_code generator)

**Purpose:** Multi-fidelity UX generator — information architecture, mockups, and production frontend — via peer channels (drawio, html, markdown, json).

**Seam:** `Ux` toolset (`transform`, `ensure_javascript`, lifecycle from BaseContextTool)

**Dependencies:** BaseContextTool; channel classes under diagram/web/document; Stories and CleanEngineering for JS ensure

**Public API:** `Ux(fidelity, format, …)`, `transform`, `ensure_javascript`, `contexts`
