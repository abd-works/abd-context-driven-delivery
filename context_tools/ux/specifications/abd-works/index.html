IA layout specifications

43 branded page templates - one per layout in ../generic/. Pick one, open it, and alter it for the real screen instead of building from scratch.

Screen & Core Page Skeletons

  • Dashboard — Grid of modular widgets/cards for data viz and quick actions.
  • Feed — Endless vertical scroll of dynamic content (chronological/algo).
  • Split Screen — 50/50 or fixed/fluid dual-panel layout (e.g., Map + List).
  • Single Page Spa — One long-scrolling page with sticky anchor nav links.
  • Asymmetrical — Unbalanced grid elements to break monotony and guide focus.
  • Magazine Editorial — Multi-column, varied-size grids mimicking news print.
  • Full Screen Media — Immersive background video/image with minimal overlay text.
  • Parallax — Multi-layered background/foreground scrolling at different speeds.
  • Infinite Canvas — Borderless 2D pan/zoom workspace (e.g., Miro, Figma).
  • Holy Grail — Header + footer + three columns: left nav, body, right aside.
  • Card Based — Entire screen comprised of modular moveable masonry blocks.

Navigation & Navigation Housing

  • Sidebar — Left/right fixed vertical panel beside a main workspace.
  • Top Header — Horizontal bar at the top of the viewport for core paths.
  • Bottom Bar — Mobile-first sticky bottom navigation for thumb-reachability.
  • Tabbed — Inline tab headers used to switch views inside a wrapper.
  • Mega Menu — Massive multi-column dropdown panel exposed from main header.
  • Drawer Hamburger — Off-screen overlay panel that slides into view when triggered.
  • Breadcrumb — Linear horizontal path tracking the user's location hierarchy.
  • Fab Menu — Circular floating trigger opening contextual action sub-menus.
  • Rail Navigation — Ultra-skinny vertical icon-only sidebar for high-density apps.
  • Tree Navigation — Collapsible nested list layout for deep file/concept directories.

Content & Data Organization

  • Grid — Symmetrical rows and columns of uniform cards or asset previews.
  • List — Single-column vertical stack ideal for scanning text-dense items.
  • Masonry — Staggered-height columns fitting uneven content fluidly (Pinterest).
  • Carousel Slider — Linear horizontal row of elements scrolled via touch/arrows.
  • Accordion — Vertically stacked headers that expand to reveal content blocks.
  • Timeline — Central vertical/horizontal line tracking sequential events.
  • Kanban Board — Vertical columns representing workflow status stages.
  • Comparison Matrix — Side-by-side spec sheets/tables for product options.
  • F Pattern — Content aligned to a top-heavy, left-to-right scanning habit.
  • Z Pattern — Landing page elements placed along a diagonal zig-zag visual path.
  • Hero Banner — High-impact top section with headline, graphic, and core CTA.
  • Spreadsheet — Infinite rows and columns of dense editable cells.

User Actions & Overlays

  • Wizard Stepper — Linear multi-screen setup for complex sequential tasks.
  • Form — Clean single-column layout optimised for fast data entry.
  • Search Filter — Search/Omnibox paired with a persistent filtering pane.
  • Modal Dialog — Locked, centered modal window dimming out the backdrop.
  • Flyout Panel — Contextual side-sheet sliding out over the main content.
  • Empty State — Educational, graphic-rich layout shown when no data exists yet.
  • Tooltip Popover — Floating micro-box pointing directly to an interface element.
  • Skeleton Loading — Wireframe-like shapes animating while actual data fetches.
  • Toast Snackbar — Low-priority micro-banner floating momentarily at a screen edge.
  • Coachmarks Walkthrough — Guided overlay highlighting interface features sequentially.
