---
description: Do not use the filename as the first heading in a markdown file.
globs: **/*.md
---

Never open a markdown file with a heading that repeats the filename (e.g. `# my-file.md` or `# my-file`). Filenames change; headings that mirror them become stale and add no meaning.

The first heading should state the purpose or subject of the content, not where it is stored.
