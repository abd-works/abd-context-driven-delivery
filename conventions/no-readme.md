description: Never create README files unless the user explicitly asks for one.
globs: **
---

Do not create `README.md` (or any variant: `README`, `readme.md`, etc.) unless the user explicitly requests it.

A folder's entrypoint is `{folder-name}.md` (see `folder-entrypoint-file.md`). READMEs are a GitHub convention for public repos — inside a structured capability folder they are redundant noise.

If you have created a README as part of a task, delete it and replace it with the correct `{folder-name}.md` entrypoint if one does not already exist.
