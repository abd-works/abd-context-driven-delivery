# harness/apps
*App* is one CDD web app a person opens beside the chat: the CDD Kanban, the Graph app, or the Story UI editor. Its status (*AppStatus*: not installed, not running, running) is read from its folder and its ports every time it is asked, and `app.open` readies it: it installs it while it is not installed (npm install, then the page build) and answers it with its url and its *AppServer* (the *NodeScript* its server runs: its folder and its command, and the ports it tries, which on the dev lane sit `ServerLanes.DEV_APP_PORT_OFFSET` above its ports file's, the command then naming the first with `--port`), or refuses with *AppNotStarted*, which names the app, the output that says why, and the command that fixes it. `app.install` installs an app again whatever its status, as the board's Update does for the CDD Kanban, so an open page loads the new build. The chat that opens an app starts its server, so the server stops when that chat ends, as /board's did; two apps one server serves (the board's server serves the CDD Kanban and the Story UI editor) share one *AppServer*. An app is made from its *AppPackage* (its folder, `package.json`, the folders outside it its build reads, and npm) and its *AppPage* (the *AppServer* that serves it and its path there): `App(label, AppPackage(folder, imports), AppPage(server, path))`. *Apps* is the one registry of apps, `APPS` (`app.register()`, `APPS.registered`, `App.load(label)`, which refuses a label no module registered with *AppNotRegistered*). Its TypeScript language adapter is `@cdd/harness/apps/app`. It lives here, not in harness/installation, because `app.open` is an MCP operation and harness/installation imports no harness/mcp.

- **Purpose:** Give every module that owns a CDD web app one way to register it, install it, and say where it answers, apart from the module that diagnoses installs.
- **Seam (terms):** App, Apps (`APPS`), AppPackage, AppPage, AppServer, NodeScript, Npm, NpmRun, AppSources, PortProbe, AppStatus, AppNotStarted, AppNotRegistered, PackageNotInstalled, `LANGUAGE_ADAPTER_FOLDER`; the MCP operations `app.open` and `app.install`
- **Dependencies (one-way):** harness/agent_tools, harness/installation (`@language_adapter`, `@data_field`, *JsonFile*), harness/mcp (`@mcp`, `@long_call`, *ServerLane*), harness/process (*ExclusivePort*, *ProcessNotStopped*).

It sits after harness/mcp and before harness/graph. The modules that own an app import this one and register it, each with *App*, from the ports file its servers read: harness/graph the Graph app (`graph_app.py`), space/kanban the CDD Kanban and the Story UI editor, and harness/files_app the Files app. Nothing here imports a module that owns an app.

## Constraint

Register an app from the module that owns it, never from here: this module names no app.
