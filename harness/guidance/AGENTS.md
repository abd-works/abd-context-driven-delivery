# PracticeGuidance

- Reach a fidelity's Clean Engineering companion through **`FidelityGuidance.clean_engineering`**, and its text through that fidelity's `companion_instructions`. A render carries its companion on **`RenderRequest.companion`**. A practice's current fidelity is fixed when the practice is made, and an action holds the fidelity it works at, so never read a companion from the shared practice. Do not add `ce()` or re-join companion text in a subclass `guidance`.
- Render at the fidelity a call works at with **`FidelityGuidance.render`** or `render_files`; **`PracticeGuidance.render`** renders at the fidelity the practice was made at. Both go through the practice's held **`PracticeFormats`** (`practice.formats`); pass `formats=` to the constructor, and name a `formats_type` subclass when a practice's formats parse or convert in a way of their own. Do not copy parse/render onto the practice. Pass an object model when you already have one. Pass a context tool when the artifacts live in that tool's workspace — code layer instantiates the model from source files, not markdown.
- Put every format adapter under `{practice}/model/{format}/`. Canonical types live in `model/`. Do not add `document/`, `diagram/`, `code/`, `web/`, or a named `{practice}_model` package beside `model/`.
- **`Guidance.tools` includes `@Hook` members.** Install walks `tools`; if `inject_rules` is omitted, chat edits never enroll and no practice rules load.
- **`PracticeGuidance.inject_rules` walks shared rules and every fidelity glob.** Shared CE rules have no file globs; code lives on the code fidelity (`**/*.py`). Matching only `self.rules` on the practice injects nothing for a catalog Python edit. Inject on the file path from the tool payload whenever that path matches a glob — any folder, any file tool.
- **Name Guidance, a toolset, an operation, a tool, or instructions — not a host.** MCP host and hook server keep those names. Do not use host as a stand-in for any of the agent types.
- **Skill and MCP copy for `instructions` is `overview`.** Do not fall back to the guidance section, and do not add a `prompt_message` property.
- **Keep helpers on the class that uses them.** A practice's `key` is also its install folder name. Hook path matching and toast labels live on `Guidance` as instance methods. Do not add module-level functions or `@staticmethod` for work that always runs on an instance.
