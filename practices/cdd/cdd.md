## Overview

Orchestrate stories, domain, experience, modules, and behavior from a shared shape of the solution down to a working slice.

## Fidelities

### discovery

```yaml
default_format: markdown
stage: discovery
```

#### Overview

Shape the whole solution: the journey, the domain, the experience, and the modules.

### spec

```yaml
default_format: markdown
stage: specification
```

#### Overview

Specify one slice of the journey as scenarios, domain behavior, and the experience.

### engineer

```yaml
default_format: python
stage: implementation
```

#### Overview

Deliver that slice as working code.
