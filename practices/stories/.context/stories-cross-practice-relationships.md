# Stories graph relationships that cross a practice

Recorded when `harness.graph.working_copy` links story nodes to clean engineering (and related) nodes. `owns` and `scopes` stay inside stories.

Cross-practice kinds include uses (epic → module), invokes (step → operation/property), demonstrates and retrieved-using (example → class/operation), and observes (then step → example).

Markdown and code channels copy the story tree from files. The graph holds the cross-practice edges for explore, validate, and rule checks.
