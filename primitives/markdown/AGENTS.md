# markdown

- This package extracts co-located markdown (folder, file, or section) and converts it to HTML. Do not add instruction slots, docstring expansion, tool invokers, or recipe assembly here — those belong on `Guidance.instructions` and `@agent_instructions`.
- Locate folder, file, and section with `AssetLocator` / `AssetLocation` in this package. Do not revive `primitives/assets`.
