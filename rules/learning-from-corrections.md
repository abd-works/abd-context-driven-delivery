# Learning From Corrections

When the user corrects work you generated, fix the work in the artifact that is wrong.

**Never create or update `AGENTS.md`.**

**Create `corrections.log`** in the folder that holds the corrected work (create the file if it is missing). Append the mistake and the correction.
