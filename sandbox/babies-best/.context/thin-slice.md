# Thin Slice — Babies Best

**Sources / context:** `.context/babies-best-sketch.md`; `.context/story-map.md`

## Product / Feature Name

Babies Best — NYC parent curation for clothing and things-to-do (0–2).

## Increments

### Increment 1: Discover Nyc Activities

**Outcome:** A parent with a baby age band can open Things to Do, restore or choose place (borough → neighborhood, optional citywide), filter by kind, browse evergreen places and dated events for that age, and open matching detail screens. Save-to-list is a handoff seam only.

**Stories in this increment:**

- *Browse Activities For Age And Place*
- *Choose Place On First Visit*
- *Filter By Borough Then Neighborhood*
- *Include Citywide Activities*
- *Filter Activities By Kind*
- *Override Age Band On Activities*
- *Show Empty Place Results*
- *Open Evergreen Activity Detail*
- *Open Dated Event Detail*
- *Save Activity To List From Detail*
