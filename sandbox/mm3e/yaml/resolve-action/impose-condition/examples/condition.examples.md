# Examples — Impose Condition

From HeroesHandbook.md lines 1254–1425. A lesser condition yields when the handbook names a condition that supersedes it. A combined condition can lose one part.

| Basic condition | Observable effect | Superseded by |
| --- | --- | --- |
| compelled | free actions and one standard action, both chosen by the controlling character | controlled |
| controlled | actions each turn are dictated by the controlling character | — |
| dazed | free actions and one standard action | stunned |
| debilitated | one or more abilities lowered below -5 | — |
| defenseless | active defenses 0; a routine attack is allowed; a normal hit is a critical hit | — |
| disabled | -5 circumstance penalty on the named checks | debilitated, when it is the same traits |
| fatigued | hindered; recovers after an hour of rest | — |
| hindered | half speed, -1 speed rank | immobile |
| immobile | no movement from the spot; actions still allowed unless another condition forbids them | — |
| impaired | -2 circumstance penalty on the named checks | disabled, when it is the same traits |
| normal | unaffected by other conditions | — |
| stunned | no actions, including free actions | — |
| transformed | traits altered; power point total does not increase | — |
| unaware | no interaction or Perception checks, and no action based on them | — |
| vulnerable | active defenses halved, round up | defenseless |
| weakened | power points lost in a trait | debilitated |

Defenseless attack values. **Seed** is the character the condition leaves behind. **Interaction** is the attack the player then makes. Defense class 10 is 10 plus a defense bonus of 0.

| Example | Role | State |
| --- | --- | --- |
| defenseless Parry | Seed | Parry bonus 0 after defenseless |
| routine attack on defenseless | Interaction | attack bonus +5, routine die 10, result 15, defense class 10, hit |
| normal hit on defenseless | Interaction | attack bonus +4, die 11, result 15, defense class 10, critical hit |
| impaired Fighting | Seed | impaired on Fighting |
| disabled Fighting | Seed | disabled on Fighting |
