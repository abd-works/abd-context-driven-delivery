# Examples — Spend Hero Point

From HeroesHandbook.md lines 1467–1541. Players start a session with 1 hero point. Spending one is a reaction. Unspent points reset at the next adventure.

| Example | Spend | Result |
| --- | --- | --- |
| session start | — | 1 hero point |
| edit scene | 1 | an unstated detail is added, such as defoliant chemicals in the lab |
| heroic feat | 1 | one rank of a non-fortune advantage until the end of the next turn |
| improve roll | 1 | reroll; a second roll of 1–10 counts as that roll plus 10; take the better |
| inspiration | 1 | a significant hint from the Gamemaster |
| instant counter | 1 | a reaction to counter an effect |
| recover dazed | 1 | dazed is removed without an action |
| recover exhausted | 1 | exhausted becomes fatigued |
| award | Gamemaster gives 1 | the hero point count increases |
| reset | next adventure | the count is 1 |
