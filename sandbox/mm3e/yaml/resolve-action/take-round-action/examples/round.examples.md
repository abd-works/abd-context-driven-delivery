# Examples — Take Round Action

From HeroesHandbook.md lines 809–814 and 1220–1252.

| Example | Action | Allotment |
| --- | --- | --- |
| one round | six seconds | one turn per character |
| standard | attack or use a power on something | one standard action in the round |
| move then standard | move, then the standard action | both, move is not split |
| standard then move | standard action, then the move | both |
| second move | standard action traded away | two move actions |
| free | talk, drop an object, end a power, activate or maintain a power | as many as the Gamemaster allows |
| reaction | a response when circumstances call for it | does not spend the standard or move action |
