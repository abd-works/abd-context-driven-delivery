# gear/equipment

Devices, equipment, weapons, armor, inventing, and constructs on the hero sheet. Holds typed Effect from powers (no effect-id strings). Peer under gear/ — not a base for HQ/vehicles.

- **Seam (terms):** Equipment, Device, Construct
- **Dependencies (one-way):** `character`, `powers`
