# skills

Owns Mutants & Masterminds skill training and untrained use on the hero sheet. Skills are traits keyed to a typed Ability from character (no ability-key strings).

## Modules fidelity

### Module `skills`

- **Purpose:** Train skill ranks and attempt skill checks; integrate with character point totals and ability keys.
- **Seam (terms):** Skill
- **Dependencies (one-way):** `character`, `checks`
- **Build order:** see `sandbox/.context/sessions/discovery/module-build-order.md`
