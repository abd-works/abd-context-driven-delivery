# A validation report finds an earlier fidelity's newest report on disk each time it is read

A *ReportFile* answers for an earlier fidelity's rules only while no newer report of that fidelity exists, so reading it lists that fidelity's reports folder (`_has_newer_report`, through `ReportFile.from_fidelity`). We keep that listing instead of holding each fidelity's latest report on its *FidelityGuidance*: the fidelity lives as long as the cdd server holds its session, and another chat or another process validates and writes a newer report at any time, so a held latest report would answer from a report that is no longer the newest. The listing happens once per report read (`_answered_rules` is read once per *ReportFile*), and the board reads each ticket's progress once per board read.
