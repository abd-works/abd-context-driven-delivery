# A fidelity's label and its skill command will come from its guidance, which the harness sends

The board page still cuts a fidelity's label out of its slug (`PracticeClient.fidelityNameOf`, `story-map` from `stories-story-map`) and builds the slash command of its skill (`skillOf`, `/practices-{practice}-{fidelity}`), which repeats how the installer names a skill folder (`FileInstallation` in `harness/installation/files.py`). Both answers belong to the fidelity's guidance, which the harness sends in every fidelity's data, so the page should only show them. The decided steps are: (1) `harness/guidance` sends each *FidelityGuidance*'s label, and `harness/installation` gives it the slash command of the skill the installer publishes for it, from the same naming the installer writes the skill with; (2) the page deletes `fidelityNameOf` and `skillOf` and shows those two fields. The board module keeps the page's two helpers until step 1 lands, because the naming is the installer's and this module may change the harness only to follow a rename.
