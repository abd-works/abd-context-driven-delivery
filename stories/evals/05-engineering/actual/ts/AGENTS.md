# TypeScript Test Files — Agent Rules

## Naming

| Element | Convention |
|---|---|
| File | `{lowest-sub-epic}-{layer}.test.ts` — named after the **lowest-sub-epic**, never the story |
| Class | `{StoryPascalCase}{Layer}` — named after the **story** |
| Method / describe | Named after the **scenario outcome** |

Layers: `domain`, `server`, `e2e`. Include only layers that exist and are meaningful.

## Imports — named destructured only

```typescript
// CORRECT
import { seedSourceAccount, postTransferHttp, resetState } from '../compose-transfer-helpers'

// WRONG — never do this
import * as H from '../compose-transfer-helpers'
import * as helpers from '../compose-transfer-helpers'
```

Call imported functions directly by name. Never via a namespace prefix.

## Step strings — always literal

Every `given`, `when`, and `then` step must appear as a **literal string** in the test body. A reader must see exactly which steps run in what order without tracing into any helper.

```typescript
// CORRECT
await tier.given['Transfer T-001 has Memo {existing_memo}']()
await tier.when['the Treasurer Alice attaches the Memo to Transfer T-001']()
await tier.then['Transfer T-001 has Memo {transfer_memo} when {memo_saved} is true']()

// WRONG — no loops over arrays
for (const step of scenario.given) { await tier.given[step]() }
```

GWT step implementations live in the tier class. The test body wires them by exact step string key.

## Tier bodies — no stubs at engineering fidelity

At engineering fidelity every tier body must be **implemented** — no `// TODO`, no `throw new Error('not implemented')`. A stub body is a scanner violation.

## story-types.ts and story-runner.ts

These files are generated by the code path from `stories/templates/`. **Never edit them.** If they need to change, update the template and re-run the scaffolder.

## Diagnose flip

After **2 consecutive failed fix attempts** on the same test file — stop. Do not touch production code again until you have read `stories/behavior/agentic-repair-loop.md` and run the full diagnose discipline.
